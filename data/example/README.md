# Example data

This folder should contain small, fully de-identified example tables so that
readers can inspect the expected input format. Suggested contents:

- `asv_count_example.tsv` — first ~50 ASVs x ~10 samples from the clean count table
- `taxonomy_example.tsv` — matching taxonomy rows
- `metadata_template.tsv` — column names and value types only, no real patient data

Full raw sequencing data are deposited in NCBI SRA (see main README).
Clinical metadata are not distributed because of patient-privacy restrictions.
